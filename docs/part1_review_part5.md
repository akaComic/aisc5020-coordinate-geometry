# 第一部分对第五部分对应性推导的复核记录

日期：2026-10-16。范围：本地 `docs/part5_report.tex` 的 Proposition P4、signed-permutation 引理及边界说明，对照 `eigenbasis.py`、公共 runner 和现有测试。本文是本次辅助完成的技术复核记录，仍需负责人阅读确认，不代表另一位组员已经签署 review。

## 对应性论证

P4 的假设足够：基 $V$ 固定正交、$H=VDV^T$、$w_0=Vz_0$、两端同参数和同一下标、初始矩为零。归纳假设下 $V^THw_{t-1}=Dz_{t-1}$，两端输入 Adam 的梯度完全相同，故一阶矩、二阶矩、bias correction 和正的 epsilon 分母都相同。方向相同后，映回 $Vd_t$ 保持 $w_t=Vz_t$。该证明允许重复特征值，因为两端指定的是同一个基。

代码核对：`eigenbasis_adam_step` 先算 `prepared.vectors.T @ gradient`，调用共同的 `adam_direction` 在该基中累积矩，再将方向乘基返回；公共 runner 在循环前准备基，初始矩为零。它与证明的更新顺序一致。没有把环境中的二阶矩直接当作特征基中的二阶矩。

## 基的歧义

signed-permutation 引理正确：一阶矩随带符号排列变换，二阶矩随无符号排列变换，归一化后的方向随带符号排列变换；物理方向保持一致。简单谱的精确正交特征基满足此关系。

重特征空间内的一般旋转没有这一性质。报告的 $H=I_2$、$w_0=(1,0)^T$、$45^\circ$ 基例子给出不同方向；它不反驳指定共同基的 P4。近重根的浮点诊断也正确区分了“小分解残差”和“小轨迹误差”，没有把 residual 当作前向轨迹保证。
